# Архітектура (усе безкоштовне, без платних API)

## Принцип
Чиста клієнтська статика (SPA). Уся «розумна» логіка — у браузері. Без платних сервісів,
без обов'язкового бекенду. Деплой — статичний білд на ваш Oracle nginx через GitHub Actions.

## Стек
- **Vite + React + TypeScript** (react-swc) — як `aurora-department-site`.
- Без UI-фреймворків: власний CSS у бренд-стилі Aurora (жовтий `#FFDD00`, червоний `#FF0000`,
  чорний, білий; заокруглення; Montserrat з Google Fonts).
- Без бекенду для MVP. Інтеграція з платформою — прямий `fetch` POST на її endpoint.

## Модулі та безкоштовні заміни платних сервісів

| Потреба | Безкоштовне рішення | Примітка |
|---------|---------------------|----------|
| Геокодинг адреси → координати | **Nominatim (OpenStreetMap)** публічний API | без ключа; дотримуємось rate-limit (1 запит/сек, User-Agent) |
| Посилання на Google Maps | генерований URL `https://www.google.com/maps/search/?api=1&query=...` | ключ не потрібен |
| Мапа для перевірки/редагування точки | **Leaflet + OSM tiles** | безкоштовно, без ключа |
| Розпізнавання голосу | **Web Speech API** (`webkitSpeechRecognition`, `lang=uk-UA`) | вбудовано в Chrome/Edge |
| Парсинг тексту → поля | **власні регулярки/евристики** | без LLM; покриває формати менеджерів |
| Парсинг вартості | **власний нормалізатор** | грн/USD/EUR, за м²/за об'єкт, з/без ПДВ |
| Текст із PDF | **pdfjs-dist** | безкоштовно |
| OCR з фото (опційно) | **tesseract.js** | безкоштовно; вмикати за потреби (важкий) |
| LLM (опційно) | заглушка `aiProvider` | під'єднати, лише якщо буде безкоштовний ендпоінт |

## Автозаповнення без LLM (як це працює)
AI-поле приймає вільний текст або голос. `extractFields()` проганяє його через набір
екстракторів:
- площа: `\d[\d\s]*\s*(м2|м²|кв\.?м)` → площа, м²
- висота: `висот\w*\s*(до ферм)?\s*([\d.,]+)` → висота
- вартість: делегується нормалізатору вартості
- населений пункт/область: словник міст/областей + «X км від Y»
- відстані до об'єктів: «Мукачево 15 км» тощо
Знайдене підставляється у поля й підсвічується (щоб менеджер перевірив).

## Курс валют для нормалізації
Безкоштовно: НБУ публічний API `https://bank.gov.ua/NBUStatService/v1/statdirectory/exchange?json`
(без ключа). Кешуємо на день. Fallback — ручний курс у налаштуваннях.

## Підсвітка валідації
- **Червоне** = обов'язкове (`*`) і порожнє → блокує «Відправити», не блокує «Зберегти».
- **Жовте** = бажане і порожнє → попередження + підказка, не блокує.
- Кожне підсвічене поле має текстову підказку (`hint`).

## Збереження й відправка
- Автозбереження чернетки в `localStorage` (debounce). Відновлення при поверненні.
- «Зберегти»: вгорі, внизу, + плаваюча кнопка (sticky).
- «Відправити»: спершу автозбереження → валідація обов'язкових → POST на платформу.

## Інтеграція з платформою (заглушка до отримання API)
`submitToPlatform(payload)` шле POST на `VITE_PLATFORM_ENDPOINT`. Поки endpoint невідомий —
працює в режимі «локальний лог + вивантаження JSON». Мапінг полів → `docs/SPEC-fields.md`.
Нормалізована вартість додається в опис для порівняння пропозицій.
