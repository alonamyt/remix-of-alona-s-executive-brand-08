# SPEC — поля форми та пакет для інтеграції з платформою

Цей документ описує, **що саме форма віддає платформі** при відправці, і як
влаштована нормалізована вартість для порівняння об'єктів.

## Формат пакета (payload)

При натисканні «Відправити» форма формує об'єкт:

```json
{
  "fields": { "<name>": "<value>", ... },
  "attachments": [ { "name": "...", "size": 123, "type": "image/png" }, ... ]
}
```

- `fields` — усі поля форми за їхніми `name` (як у розмітці `index.html`).
- `attachments` — метадані вкладень. Самі файли у проді передаються як
  `multipart/form-data` (`file_0`, `file_1`, …) на inbox-приймач у закритому контурі.
- Приймач (у VPN) очікує поле `payload` = JSON-рядок і файли окремими полями.
  Endpoint задається константою `INBOX_ENDPOINT` в `app.js` (поки порожній — демо-режим).

## Ключові поля (вибірка)

| name | Опис | Приклад |
|------|------|---------|
| `objectType` | Тип об'єкта | Складське приміщення / Земельна ділянка |
| `deal` | Тип угоди | Оренда / Продаж / Оренда або продаж |
| `region`, `city`, `address` | Локація | Хмельницька / Хмельницький / вул. … |
| `areaOffered` | Площа, що пропонується, м² | 6000 |
| `areaTotal` | Загальна площа будівлі, м² | 6000 |
| `height` | Чиста робоча висота, м (може бути текст) | `мінімум 6,5, по центру 8,5` |
| `priceRaw` | Вартість як увів менеджер | `7 USD/м² на місяць` |
| `priceNorm` | Нормалізована вартість (текст для людини) | `290,5 грн без ПДВ/м²` |
| `priceNormData` | **Машиночитна вартість для порівняння (JSON)** | див. нижче |
| `vat` | Чи включено ПДВ | Так / Ні / Власник не платник ПДВ |
| `rentTerm` | Мінімальний термін оренди, міс. | 12 |
| `geo` | Посилання на Google Maps | https://…/maps/search/?… |

## Нормалізована вартість для інтеграції (`priceNormData`)

Приховане поле `priceNormData` містить JSON, за яким платформа **порівнює об'єкти**
за єдиною метрикою. Заповнюється автоматично з `priceRaw` + `vat` + `deal`.

```json
{
  "raw": "7 USD/м² на місяць",
  "amount": 7,
  "currency": "USD",
  "rate": 41.5,
  "vatIncluded": false,
  "basis": "per_sqm",
  "period": "month",
  "amountUAHexclVAT": 290.5,
  "amountUAHinclVAT": 348.6,
  "canonicalValue": 290.5,
  "canonicalUnit": "UAH_exclVAT_per_sqm_per_month"
}
```

### Канонічна метрика (`canonicalUnit` / `canonicalValue`)

Усі об'єкти зводяться до однієї метрики, щоб їх можна було порівнювати:

| Ситуація | canonicalUnit | Приведення |
|----------|---------------|------------|
| Оренда, за м² | `UAH_exclVAT_per_sqm_per_month` | грн без ПДВ /м²/міс (річна ставка ÷ 12) |
| Оренда, за об'єкт | `UAH_exclVAT_per_object_per_month` | грн без ПДВ /об'єкт/міс (річна ÷ 12) |
| Продаж, за м² | `UAH_exclVAT_per_sqm` | грн без ПДВ /м² |
| Продаж, за об'єкт | `UAH_exclVAT_per_object` | грн без ПДВ /об'єкт |

Правила приведення:
- Валюта → гривня за курсом `rate` (у проді — НБУ на дату; зараз демо-курс у `RATES`).
- ПДВ → усе зводиться до **без ПДВ** (`amountUAHexclVAT`); `amountUAHinclVAT` — довідково.
- Період → **місяць** (річна ставка ділиться на 12), щоб оренда була співставна.
- Якщо `vatIncluded: null` — ПДВ не уточнено, платформі варто позначити як неточне.

> Для порівняння пропозицій на платформі використовуйте `canonicalValue` разом із
> `canonicalUnit` (порівнювати можна лише значення з однаковим `canonicalUnit`).
