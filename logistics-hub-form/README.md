# Logistics Hub — зовнішня форма пропозиції об'єкта

Зовнішня (публічна) форма для регіональних менеджерів Аврори. Дословно повторює
поля платформи `logistics-hub.rnd-dev.avrora.lan` («Пропозиція об'єкта»), але
додає розумні функції, яких немає в корпоративній MS Forms.

## Контур і доступи

- **Репозиторій — приватний.** Відкритий для Іллі (адміністратор платформи).
- **Форма — публічна**, доступна ззовні за посиланням (менеджери заповнюють з телефону,
  без VPN).
- **Платформа `logistics-hub.rnd-dev.avrora.lan` — у закритому контурі за VPN.**
- Потік даних односторонній і безпечний: **форма → проміжний inbox → (всередині VPN)
  платформа забирає й заносить**. Зовнішня форма ніколи не має прямого доступу до `.lan`.

Поточний деплой: `https://rau-expo.rnd-avrora.com.ua/logistics-hub-form/`
(GitHub Actions → Oracle nginx).

## Де що лежить

```
logistics-hub-form/
  prototype/          # ← РОБОЧА ВЕРСІЯ (самодостатня, без збірки)
    index.html        #   верстка, стилі, бренд Aurora
    app.js            #   уся логіка: поля, умовність, нормалізація, AI, файли
  docs/
    SPEC-fields.md    #   реєстр полів (джерело істини) — скріни платформи + Word v2 + FAQ
    ARCHITECTURE.md   #   рішення по стеку і безкоштовних сервісах
  src/                # альтернативна React-версія (не деплоїться зараз)
```

**Робоча версія — `prototype/`.** Відкривається як статика, деплоїться як є.

## Що вміє форма (усе безкоштовно, без платних API)

- Усі поля й випадаючі списки Склад / Земля з умовною логікою (залежні поля).
- **Нормалізація вартості**: будь-який формат (`5$`, `5 дол/м²`, `130 грн з ПДВ`,
  `90 000 за об'єкт`) → єдине `грн без ПДВ/м² (в дужках з ПДВ)`. Курс — НБУ (безкоштовно).
- **AI-помічник** (локальні евристики, без LLM): чат + голос (Web Speech API) +
  розпізнавання файлів. Витягнуте з фото/файлів помічається бейджем «🔍 перевірте».
- **Розпізнавання файлів**: фото (OCR Tesseract.js), PDF (pdf.js, + OCR для сканів),
  DOCX (JSZip), XLSX (SheetJS). Технічні довідки/оголошення автоматично заповнюють поля.
- **Автогеолокація**: Google Maps лінк з міста/адреси (генерується лише за наявності
  міста; без області — попередження «неточно»). Кнопки Переглянути / Копіювати.
- **Аналіз оточення**: OpenStreetMap (Overpass + Nominatim) — небезпечні об'єкти в ~800 м.
- **Мініатюри файлів**: фото — прев'ю, PDF/DOCX/XLSX/відео — значок за типом.
- **Підсвітка**: 🔴 обов'язкове, 🟡 бажане (легенда один раз збоку, без повтору під полями).
- Кнопки **Зберегти** (вгорі, внизу) + **Відправити**; автозбереження чернетки в localStorage.

## Точки інтеграції з платформою (для Іллі)

Усе зібрано в одному місці — функція **`submitForm()` у `prototype/app.js`**.

- `collect()` повертає обʼєкт полів форми (ключі — `name` атрибути інпутів).
- `payload = { fields, attachments }` — готовий пакет. Зараз він логується в консоль
  (демо). Для проду: замінити демо-alert на `fetch(INBOX_ENDPOINT, {method:'POST', body})`,
  де `body` — `FormData` з полями + файлами (файли в масиві `attachments`, поле `.file`).
- **Мапінг полів форми → полів платформи**: див. `docs/SPEC-fields.md`. Нормалізована
  вартість (`priceNorm`) призначена для порівняння пропозицій — варто занести в опис/окреме поле.
- Статуси workflow: Новий → На розгляді → **На погодженні** → Погоджено → Збір документів
  → Юридичне опрацювання → Запуск.

## Залежність від інтернету (важливо)

- Працює **скрізь у браузері** (без інтернету до платформи): форма, нормалізація, підсвітка,
  чернетка, голос, OCR, файли.
- Потребує **звичайного інтернету** (не VPN): аналіз оточення (OpenStreetMap), курс НБУ, CDN.
- Потребує **платформи у VPN**: лише фінальний заліт даних (через inbox).

## Локальний запуск

Просто відкрити `prototype/index.html` у Chrome/Edge (голос і деякі функції потребують
цих браузерів). Для голосу/камери потрібен `https://` або `localhost` (не `file://`).
