# Logistics Hub — зовнішня форма пропозиції об'єкта

Розумна зовнішня форма для регіональних менеджерів Аврори. Дословно повторює поля
платформи `logistics-hub.rnd-dev.avrora.lan` («Пропозиція об'єкта»), додає AI-помічник,
нормалізацію вартості, автогеолокацію, підсвітку обов'язкових/бажаних полів.

## Що працює (усе безкоштовно, у браузері)

- Повна форма: Склад / Земельна ділянка, усі секції, випадаючі списки, умовна логіка.
- **AI-помічник**: опис словами / голосом (Web Speech API) / файлом.
  - OCR фото — Tesseract.js (`ukr+rus+eng`).
  - PDF — pdf.js (текстовий шар + OCR для сканів).
  - DOCX — JSZip → `word/document.xml`.
  - XLSX — SheetJS.
  - Витягнуті з файлів дані позначаються «🔍 з фото/файлу — перевірте».
- **Нормалізація вартості**: будь-який формат (`5$`, `5 дол/м²`, `130 грн з ПДВ`,
  `90 000 за об'єкт`) → «грн без ПДВ/м² (в дужках з ПДВ)». Курс — НБУ (безкоштовно).
- **Автогеолокація**: Google Maps лінк з міста/адреси (тільки коли є місто),
  кнопки Переглянути / Копіювати, попередження про неточність без області.
- **Аналіз оточення**: OpenStreetMap (Nominatim + Overpass) — небезпечні об'єкти в ~800 м.
- **Підсвітка**: 🔴 обов'язкове, 🟡 бажане (легенда один раз, без повторів під полями).
- Автозбереження чернетки, кнопки Зберегти (вгорі/внизу) + Відправити.
- Мобільна адаптація (телефон + ноут).

## Структура

- `prototype/` — робоча статична форма (index.html + app.js). **Це те, що деплоїться.**
- `docs/` — SPEC полів і архітектура.
- `src/`, `vite.config.ts` — заготовка React-версії (не використовується для деплою).
- `tools/` — допоміжні скрипти.

## Контур і безпека

Платформа — у закритому контурі за VPN. Форма — зовнішня. Потік даних односторонній:
форма → проміжний inbox → (усередині VPN) платформа забирає. Зовнішня форма не має
доступу до закритого контуру. Реальна інтеграція під'єднується окремо (заглушка на відправці).

## Локальний запуск

```powershell
npx.cmd --yes serve -l 4180 prototype
```

Деплой на Oracle nginx — через GitHub Actions (`.github/workflows/deploy-logistics-hub-form.yml`),
зовнішній шлях `/logistics-hub-form/`.
