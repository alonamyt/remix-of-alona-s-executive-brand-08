# Logistics Hub — розумна форма пропозиції об'єкта

Зовнішня (публічна) форма для регіональних менеджерів Аврори. Дословно повторює
поля платформи `logistics-hub.rnd-dev.avrora.lan` («Пропозиція об'єкта»), але
додає розумні функції, яких немає в корпоративній MS Forms.

## Контур і безпека

- **Форма — публічна**, доступна ззовні за посиланням (менеджери заповнюють з телефону,
  без VPN).
- **Платформа `logistics-hub.rnd-dev.avrora.lan` — у закритому контурі за VPN.**
- Потік даних односторонній: **форма → проміжний inbox → (всередині VPN) платформа
  забирає й заносить**. Зовнішня форма ніколи не має прямого доступу до `.lan`.

Поточний деплой: `https://rau-expo.rnd-avrora.com.ua/logistics-hub-form/`
(GitHub Actions → Oracle nginx, workflow `.github/workflows/deploy-logistics-hub-form.yml`).

## Структура (одне джерело істини)

```
logistics-hub-form/
  prototype/          # ← РОБОЧА ВЕРСІЯ, її і деплоїть GitHub Actions
    index.html        #   верстка, стилі (бренд Aurora), розмітка форми
    app.js            #   уся логіка: списки, умовні поля, нормалізація ціни,
                      #   AI-евристики, OCR/PDF/DOCX/XLSX, автогео, автозбереження
  docs/               # специфікація полів (SPEC-fields.md, ARCHITECTURE.md)
  README.md
```

> Ніяких `src/`, `preview/`, `backups/` — редагуємо прямо `prototype/`, щоб не
> плутати версії. Це саме те, що бачить користувач на проді.

## Функції (усе безкоштовне, без платних API)

| Функція | Технологія | Працює де |
|---------|-----------|-----------|
| Форма, списки, умовна логіка, розділення Склад/Земля | чистий JS | скрізь |
| Нормалізація вартості (грн без ПДВ/м² + в дужках з ПДВ) | JS + курс НБУ | скрізь (курс — інтернет) |
| Підсвітка червоне/жовте + легенда | JS | скрізь |
| Автозбереження чернетки | localStorage | скрізь |
| Голосове введення | Web Speech API | Chrome/Edge |
| OCR фото | Tesseract.js (CDN) | інтернет |
| Читання PDF / DOCX / XLSX | pdf.js / JSZip / SheetJS (CDN) | інтернет |
| Автогеолокація (лінк Google Maps + аналіз оточення) | Nominatim + Overpass (OSM) | інтернет |
| Відправка на платформу | POST на inbox (заглушка) | потрібен endpoint у VPN |

## Локальний запуск (спробувати перед пушем)

Форма — статична, тож для локальної проби потрібен лише Node:

```powershell
# у теці logistics-hub-form/prototype/
node serve-local.mjs
# відкрити http://localhost:5188/
```

Це віддає `index.html` + `app.js` так само, як прод-nginx. Зручно перевірити
розпізнавання, нормалізацію вартості й вигляд перед `git push`.

> Для проби інтеграції: у демо-режимі при «Відправити» пакет (`payload`) пишеться
> в консоль браузера (`console.log`). Коли зʼявиться inbox-endpoint у VPN — вписати
> його в `INBOX_ENDPOINT` (`app.js`), і форма слатиме `multipart/form-data`
> (поле `payload` + файли). Опис пакета — `docs/SPEC-fields.md`.

## Вартість для порівняння (інтеграція)

Крім тексту `priceNorm` (для людини), форма рахує **канонічну метрику** й кладе її
в приховане поле `priceNormData` (JSON). Усі обʼєкти зводяться до однієї одиниці:
оренда — `грн без ПДВ /м²/міс` (річна ставка ÷ 12), продаж — `грн без ПДВ /обʼєкт`.
Саме за `canonicalValue` + `canonicalUnit` платформа порівнює пропозиції.
Деталі — `docs/SPEC-fields.md`.

## Флоу роботи

Локально → показ → якщо ок → push на GitHub → зовнішній деплой автоматично
(push у `main`, що зачіпає `logistics-hub-form/prototype/**`).

## Кеш

`index.html` підключає `app.js?v=N`. Після змін у `app.js` піднімаємо `N`,
щоб браузери підтягнули нову версію.
